# qleisliup v0.1.0

The first GitHub source release of the Rust Qleisli toolchain lifecycle manager.
Its design contract is **Exact / Immutable / Authenticated / Explicit /
Independent**.

## Included

- Offline exact toolchain selection, inspection, defaults, and repository pins.
- Local toolchain registration and six Unix proxies: qli, qleisli, qargo,
  qlippy, qlifmt, and qlidoc. Compiler-only local links remain unauthenticated.
- TUF authentication through tough, persistent root/rollback state, immutable
  release identities, bounded extraction, and transactional toolchain install/removal.
- The qleisliup-init bootstrap and manager self-update implementation, including
  staged native version probes, ownership checks, and atomic publication.
- Regression fixes for manager invocation aliases, surviving probe helpers,
  archive path/receipt aliases, metadata limits/cache compaction, and bounded
  local registry writes.
- English specifications, implementation/validation records, Apache-2.0 licensing,
  and CI for Rust 1.85.0 and stable on the initial three platforms.

## Distribution status

Production distribution URLs and the initial trusted root remain unconfigured.
New install/sync operations, bootstrap, and self-update fail closed when they
require production distribution. Isolated signing keys and repositories are
test-only and unreachable from the production CLI. Existing valid exact
installations can be reused offline; local links and proxies are usable.

This release supplies source through GitHub's automatic source archives. It
includes no prebuilt executables, authenticated Qleisli bundle, or production
TUF metadata. qleisliup is not published to crates.io; Cargo.toml retains
publish = false. Windows and Linux ARM64 remain deferred.

The selected standalone compiler does not change qargo's linked checker.
Receipts record authentication at installation, not current integrity or
mathematical correctness. Real upstream bundles, production trust/bootstrapping,
and storage fault/power-loss behavior remain separate release gates.

## Build from source

Rust 1.85 or newer, a C/C++ toolchain, and CMake are required. macOS uses Xcode
command-line tools; Linux musl also needs musl-tools.

```sh
cargo build --locked
target/debug/qleisliup --help
target/debug/qleisliup --version
target/debug/qleisliup-init --help
```

## Validation

Local macOS ARM64 checks passed on Rust 1.85.0 and Homebrew stable Rust 1.98.1:
builds of both executables, 135 test executions per compiler, formatting,
clippy with warnings denied, and CLI smoke checks for both executables.
The 135 executions comprise the shared 46-case unit suite in each binary
harness plus 43 integration cases. Details and review corrections are recorded
in docs/implementation-plan.md, docs/review-stage3.md, and docs/review-stage4.md.

GitHub CI runs the same build, lint, test, formatting, and CLI checks on
macOS ARM64, macOS x86_64, and Linux x86_64 musl with Rust 1.85.0 and stable.
