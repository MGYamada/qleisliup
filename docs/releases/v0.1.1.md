# qleisliup v0.1.1

The first crates.io source release of qleisliup, also distributed through GitHub.
It includes the manager and bootstrap sources, packaging improvements, and three
toolchain lifecycle fixes. Prebuilt binaries and production Qleisli distribution
are not included.

## Changes

- Add crates.io metadata and an explicit source-package include list, retaining
  Apache-2.0 licensing, NOTICE, Cargo.lock, documentation, and runnable tests.
- Document Cargo installation of both qleisliup and qleisliup-init, manual proxy
  setup, and updates through the original installation method.
- Verify source packaging in CI on Rust 1.85.0 and stable for the initial hosts.
- Keep version checks tied to the package version, including CLI smoke checks
  against Cargo's normalized package manifest.
- Add native release candidate builds and a runtime smoke check with Rust
  developer tools trapped on PATH; document the Cargo-free end-user delivery goal.
- Normalize authenticated archive executable modes to 0755 and data modes to
  0644, retaining privileged-mode and missing-execute-bit rejection (#2).
- Resolve and validate `default stable` under the home mutation lock before
  freezing its exact version (#3).
- Reclaim bounded abandoned install/removal, metadata, bootstrap, and self-update
  staging without following links or deleting the active TUF generation (#4).

State formats remain unchanged. See the [publishing guide](../publishing.md) for
the release procedure.

## Source installation

Rust 1.85 or newer, a C/C++ toolchain, and CMake are required. macOS uses Xcode
command-line tools; Linux musl also needs musl-tools.

```sh
cargo install qleisliup --version 0.1.1 --locked
qleisliup --version
qleisliup-init --help
```

## Distribution status

Production distribution URLs and the initial trusted root remain unconfigured.
New toolchain downloads, bootstrap, and manager refreshes fail closed. Local
links/proxies and reuse of existing valid exact installations remain available.
Cargo installation creates neither proxy links nor bootstrap ownership, and
Cargo-installed managers must be updated with Cargo.

Publishing this crate does not publish Qleisli toolchains, authenticate upstream
bundles, or complete the production security/release gates. Windows and Linux
ARM64 remain deferred.

## Validation

On macOS ARM64, Rust 1.85.0 and stable Rust 1.98.1 passed builds of both binaries,
135 test executions each, formatting, clippy with warnings denied, and CLI smoke
checks. Source package verification passed on both compilers, including an online
`cargo publish --dry-run` on stable that stopped before upload.

The extracted package also passed compilation of all test targets, 21 focused
fixture/CLI cases, the normalized-manifest smoke check, and an isolated Cargo
release-profile installation with both executables reporting version 0.1.1.
See the [validation record](../implementation-plan.md#version-011-packaging-validation-2026-10-03)
for scope and remaining release gates.

The subsequent native-distribution preparation passed release builds and the
restricted-PATH runtime check on both local compilers, including a negative
Cargo-invocation check. The updated source package contains 43 files and its
extracted runtime check passed. These checks cover local fixtures and native
manager operation; the real Cargo-free download/install path remains planned.
