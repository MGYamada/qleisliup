# qleisliup v0.1.5

Source release reflecting the updated README notices. The
independence notice now includes qleisliup and qleisliup-init alongside Qleisli
and its other tools, uses lowercase qargo consistently, and replaces the opening
tagline. README also attributes the Rust and Cargo trademarks to the Rust
Foundation.

Cargo.toml supplies version 0.1.5 to both qleisliup and qleisliup-init. Current
documentation and CHANGELOG use that version; prior release records are retained.
Development remains temporarily suspended while the maintainer focuses on
Qleisli itself. Runtime behavior, dependency versions, and state formats are
unchanged from 0.1.4.

## Source installation

With Rust 1.85 or newer, a C/C++ toolchain, and CMake:

```sh
cargo install qleisliup --version 0.1.5 --locked
qleisliup --version
qleisliup-init --version
```

The binaries report `qleisliup 0.1.5` and `qleisliup-init 0.1.5`.
For a checkout of this version, `cargo install --path . --locked` is also supported.
See the [source installation guide](../source-installation.md)
for prerequisites, external-manager updates, and explicit local proxy setup.

## Local validation

On macOS ARM64, Rust 1.85.0 and installed rustup stable Rust 1.99.0 passed
debug builds of both binaries, all 173 test executions per compiler,
formatting including both native fixtures, clippy with warnings denied,
and CLI smoke checks. Both binaries report 0.1.5. Complete toolchains and
separate build directories resolved initial compiler-path/cache mismatches;
the full suites ran outside the local execution sandbox for the existing
Unix-socket fixture. Local documentation links, whitespace, and the version-only
Cargo.lock change were checked.

At the preparation checkpoint, release builds, runtime guard checks, package
verification, dependency audits, remote CI, and other-host execution had not
been rerun.

The exact locked graph subsequently passed cargo-audit 0.22.2 with warnings
denied against RustSec database commit
`7eebec69c352c7191b1f13eb95dd510eeca5d1de` (1,296 advisories):
217 dependencies, zero vulnerabilities, zero warnings, and no ignored advisories.

Final supported-host CI, native runtime checks, clean packaging, publish dry-run,
extracted-source and isolated-install checks, publication, and source asset
checksums are recorded in the GitHub release.

## Distribution boundary

Production endpoints and the initial trusted TUF root remain unconfigured;
prebuilt managers and production Qleisli distributions are not included.
Source publication does not configure production toolchain distribution or trust.

See the [implementation plan](../implementation-plan.md) for validation records
and the [publishing procedure](../publishing.md) for separate release steps.
