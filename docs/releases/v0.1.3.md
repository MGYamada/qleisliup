# qleisliup v0.1.3

Source release documenting the independence of Qleisli, Qargo, qlippy, qlifmt,
and qlidoc from the Rust Project and the Rust Foundation. Cargo.toml supplies
version 0.1.3 to both qleisliup and qleisliup-init. Runtime behavior, dependency
versions, and state formats are unchanged from 0.1.2.

## Source installation

With Rust 1.85 or newer and the native build
prerequisites described in the [v0.1.3 README](https://github.com/MGYamada/qleisliup/blob/v0.1.3/README.md):

```sh
cargo install qleisliup --version 0.1.3 --locked
qleisliup --version
qleisliup-init --version
```

The binaries report `qleisliup 0.1.3` and `qleisliup-init 0.1.3`.
For a checkout of this version, `cargo install --path . --locked` is also supported.

## Local validation

On macOS ARM64, Rust 1.85.0 and installed stable Rust 1.98.1 passed debug builds
of both binaries, all 173 test executions per compiler, formatting including
native fixtures, clippy with warnings denied, and the CLI smoke check. Both
binaries report 0.1.3. Unix-socket fixtures required running the full suites
outside the local execution sandbox. Release builds, runtime guard checks,
package verification, audits, remote CI, and other-host checks were not rerun
for this version-only preparation.

## Distribution boundary

Production endpoints and the initial trusted TUF root remain unconfigured;
prebuilt managers and production Qleisli distributions are not included.

See the [implementation plan](../implementation-plan.md) for validation records
and the [publishing procedure](../publishing.md) for separate release steps.
