# qleisliup v0.1.4

Source release marking the temporary suspension of qleisliup development.
Cargo.toml supplies version 0.1.4
to both qleisliup and qleisliup-init. Current documentation and CHANGELOG use
the new version. Runtime behavior, dependency versions, and state formats are
unchanged from 0.1.3.

The maintainer has decided to temporarily suspend qleisliup development to
focus on developing Qleisli itself. Development is on hold at version 0.1.4.
README's current status records this decision, and all subsequent README
sections have been removed.

## Source installation

With Rust 1.85 or newer, a C/C++ toolchain, and CMake:

```sh
cargo install qleisliup --version 0.1.4 --locked
qleisliup --version
qleisliup-init --version
```

The binaries report `qleisliup 0.1.4` and `qleisliup-init 0.1.4`.
For a checkout of this version, `cargo install --path . --locked` is also supported.
See the [source installation guide](../source-installation.md) for build
prerequisites, external-manager updates, and explicit local proxy setup.

## Local validation

On macOS ARM64, Rust 1.85.0 and installed Homebrew stable Rust 1.98.1 passed
debug/release builds of both binaries, all 173 test executions per compiler,
formatting including both native fixtures, clippy with warnings denied,
CLI/runtime guard checks, and offline source package verification.
Both binaries report 0.1.4. Initial sandboxed runs rejected the existing
Unix-socket fixture; both full suites passed outside the local execution sandbox.
Local documentation links, whitespace, and the version-only Cargo.lock change
were checked.

The exact locked graph passed cargo-audit 0.22.2 with warnings denied against
RustSec database commit `550efd3d587a29b2e2c2b21b17a440da4fede999`
(1,295 advisories): 217 dependencies, zero vulnerabilities, zero warnings,
and no ignored advisories.

Final supported-host CI, clean packaging, publish dry-run, extracted-source
and isolated-install checks, publication, and source asset checksums are recorded
in the GitHub release.

## Distribution boundary

Production endpoints and the initial trusted TUF root remain unconfigured;
prebuilt managers and production Qleisli distributions are not included.

See the [implementation plan](../implementation-plan.md) for validation records
and the [publishing procedure](../publishing.md) for separate release steps.
